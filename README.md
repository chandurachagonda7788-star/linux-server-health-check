#Llinux Server Health Check

A simple Bash script to check basic Linux server health.

## Features

- Displays hostname
- Displays IP address
- Displays system uptime
- Checks CPU usage
- Checks memory usage
- Checks disk usage
- Displays current date and time

## How to Run

```bash
chmod +x server_health.sh
./server_health.sh

This project is created for Linux server monitoring practice.
